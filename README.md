# Data Analysis Bug Project

A small data-processing project used to test autonomous software engineering workflows.

The project uses NumPy and Pandas for data cleaning, numerical calculations,
normalization, and report generation.

The repository intentionally contains bugs in the implementation.

The existing pytest test suite defines the expected behavior.
